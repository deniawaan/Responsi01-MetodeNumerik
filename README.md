# Responsi 1 Praktikum Metode Numerik

Program ini dibuat menggunakan MATLAB untuk menyelesaikan tiga permasalahan dalam Praktikum Metode Numerik, yaitu pendekatan deret Taylor dan analisis galat, Sistem Persamaan Linear (SPL), serta persamaan nonlinear.

## Program

Program terdiri dari tiga kasus:

1. **Deret Taylor dan Analisis Galat**  
   Menghitung pendekatan fungsi kosinus dan eksponensial menggunakan 23, 24, dan 25 suku. Hasilnya dibandingkan dengan fungsi eksak melalui grafik, rata-rata galat mutlak (MAE), dan rata-rata galat relatif dalam persen (MRPE).

2. **Sistem Persamaan Linear (SPL)**  
   Menentukan harga beras, telur, tepung, dan ayam per kilogram berdasarkan data belanja empat mahasiswa menggunakan metode Gauss-Seidel.

3. **Persamaan Nonlinear**  
   Menentukan jari-jari bola dan tabung menggunakan metode biseksi, kemudian menghitung volume tabung dan volume bagian tabung yang berada di luar bola.

## Teknologi

- Bahasa pemrograman: MATLAB
- Metode numerik: Deret Taylor, Gauss-Seidel, dan Biseksi

## File Repository

- `Responsi_1_Metode_Numerik.m` — source code utama program.
- `README.md` — deskripsi singkat program.

## Output Program

Program menghasilkan grafik perbandingan fungsi dan grafik persamaan nonlinear, serta menampilkan hasil perhitungan numerik pada Command Window.

**Catatan:** Pada kasus ketiga, perhitungan menggunakan asumsi volume bola sebesar 300 cm³ karena satuan pada soal tertulis cm².
